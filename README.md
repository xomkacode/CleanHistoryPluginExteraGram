# CleanHistoryPluginExteraGram

## Русский

Плагин для exteraGram, который находит и удаляет ваши сообщения в открытом чате, включая групповые комментарии. Перед удалением запрашивает подтверждение. В AyuGram использует удаление без сохранения сообщения в локальном архиве.

### Установка

1. Скачайте файл `CleanHistory.plugin` из этого репозитория.
2. Откройте файл в exteraGram и нажмите **Установить**.
3. Включите плагин в разделе **Настройки → Плагины**.
4. Откройте нужный чат, нажмите меню действий и выберите **Очистить мои сообщения**.

Автор и канал обновлений: [@homkaplugin](https://t.me/homkaplugin).

## English

An exteraGram plugin that finds and deletes your messages in the open chat, including group comments. It asks for confirmation before deleting. In AyuGram, it requests deletion without keeping a local archive copy.

### Installation

1. Download `CleanHistory.plugin` from this repository.
2. Open the file in exteraGram and tap **Install**.
3. Enable the plugin under **Settings → Plugins**.
4. Open a chat, open its action menu, and choose **Clear my messages**.

Author and updates: [@homkaplugin](https://t.me/homkaplugin).
